# Keys, layers and profile files

Add an effect and edit it inline. Each layer has selected keys, speed, color, intensity, opacity and normal/additive blending. Top layers appear above lower layers. Up to sixteen layers fit on the keyboard; the encoded profile must also fit the firmware's 4,064-byte limit.

Click a key to change its selection. Drag from a key to paint across keys; drag from empty space for a rectangle. Shift adds to a selection; Option on Mac or Alt on Windows removes. All, None, WASD and Arrows are selection shortcuts. Mapping is a separate advanced correction tool, not a step required for ordinary selection.

Selected keys are the triggers for reactive effects. Affect all keys determines how far their output reaches. For all-key reactive lighting that lights just the pressed key, choose All and leave Affect all keys off. For a WASD-triggered ripple that reaches the number pad, select WASD and turn Affect all keys on.

Use each layer's Speed for motion/fade speed. Host FPS is in Mac playback on Mac and FPS cap on Windows. A higher host FPS cannot remove Bluetooth bandwidth limits. Play on keyboard runs the firmware engine instead, with bounded work between key scans.

Play on keyboard previews without saving permanently. Save to keyboard commits and verifies the complete profile. Clear all/Remove all edits the draft; Undo restores it. Saving an empty draft turns saved lighting off. Export a JSON file for backup and sharing. Open/import a different profile, then upload it explicitly.

Five eight-layer presets are included: Neon Circuit, Matrix Overdrive, Crystal Storm, Solar Forge and Prism Arcade. Their layers combine ambient animation with reactive accents, so press keys as well as watching the idle animation.
